<tr>
<td>**외부 API 연동**</td>
<td>Maintain Communication Users</td>
<td>**통신 사용자 유지 보수**</td>
<td>외부 시스템(포스트맨, 외부 자바 서버 등)이 전용으로 사용할 API 접속 계정(Basic Auth ID/PW)을 발급하는 메뉴</td>
</tr>
<tr>
<td>**외부 API 연동**</td>
<td>Custom Communication Scenarios</td>
<td>**사용자 정의 통신 시나리오**</td>
<td>ADT에서 만든 OData V4 웹 서비스 인터페이스를 외부 개방용 시나리오 주머니에 담아 관리하는 메뉴</td>
</tr>
<tr>
<td>**외부 API 연동**</td>
<td>Communication Arrangements</td>
<td>**통신 규약**</td>
<td>위에서 만든 '통신 사용자 계정'과 '통신 시나리오'를 최종 조립하여 API 게이트웨이 방화벽을 완전히 해제하는 메뉴</td>
</tr>
<tr>
<td>**인력 관리 (HR)**</td>
<td>Manage Workforce</td>
<td>**인력 관리**</td>
<td>프로젝트에 투입할 개발자나 임직원의 인적 자원 마스터 데이터를 조회하고 관리하는 메뉴</td>
</tr>
<tr>
<td>**인력 관리 (HR)**</td>
<td>Maintain Employees</td>
<td>**임직원 유지 관리**</td>
<td>사번 계정을 기반으로 개별 직원의 인사 마스터 정보를 수정 및 유지보수하는 메뉴</td>
</tr>
<tr>
<td>**인력 관리 (HR)**</td>
<td>Import Employees</td>
<td>**임직원 임포트**</td>
<td>엑셀(CSV) 파일 등을 활용해 대량의 임직원 데이터를 시스템 데이터베이스에 일괄 인서트(Batch)하는 메뉴</td>
</tr>
<tr>
<td>**계정 및 권한**</td>
<td>Maintain Business Users</td>
<td>**비즈니스 사용자 유지 관리**</td>
<td>실제 사원 계정을 조회하고, 특정 직원에게 업무 화면 및 액션 권한 주머니를 할당하는 계정 관리 메뉴</td>
</tr>
<tr>
<td>**계정 및 권한**</td>
<td>Maintain Business Roles</td>
<td>**비즈니스 역할 유지 관리**</td>
<td>Spring Security의 권한 롤(`ROLE_ADMIN`, `ROLE_DEV`)처럼 접근 가능한 앱 화면과 제어 권한 그룹을 정의하는 메뉴</td>
</tr>
<tr>
<td>**계정 및 권한**</td>
<td>Business Role Templates</td>
<td>**비즈니스 역할 템플릿**</td>
<td>SAP 솔루션이 모듈별로 표준 제공하는 기본 권한 가이드라인 템플릿 리스트</td>
</tr>
<tr>
<td>**공통 코드 / 확장**</td>
<td>Custom Fields</td>
<td>**사용자 정의 필드**</td>
<td>DB 테이블을 직접 뜯어고치지 않고도 UI5 화면과 CDS 뷰에 새로운 가상 확장 필드를 동적으로 추가하는 메뉴</td>
</tr>
<tr>
<td>**공통 코드 / 확장**</td>
<td>Custom Business Objects</td>
<td>**사용자 정의 비즈니스 오브젝트**</td>
<td>RAP 백엔드를 통하지 않고 화면단에서 공통 코드 성격으로 쓸 간단한 데이터베이스 마스터 테이블(CBO)을 빌드하는 메뉴</td>
</tr>
<tr>
<td>**공통 코드 / 확장**</td>
<td>Custom Logic</td>
<td>**사용자 정의 로직**</td>
<td>표준 프로세스 중간에 자바 인터셉터(`Interceptor`)나 `AOP`처럼 커스텀 유효성 검증 로직을 ABAP 코드로 끼워 넣는 BAdI 확장 구역</td>
</tr>
</table>
