# 🌐 Fiddler Classic 사용 가이드 (크롬 트래픽 제어)
## 1. 초기 필수 설정 (HTTPS 복호화)
**중요:** HTTPS 암호화를 해제하지 않으면 크롬에서 패킷 내용이 깨지거나 연결 오류가 발생합니다.

1. 상단 메뉴: **Tools**➡️** Options** 이동
2. **HTTPS** 탭 선택
3. **`Decrypt HTTPS traffic`** 체크박스 활성화
4. 루트 인증서 설치 팝업창이 뜨면 모두 **[Yes]**/**[예]** 클릭
5. 설정을 저장(**OK **)하고 ** 피들러 재시작**
## 2. 특정 도메인만 필터링하기
광고 서버나 불필요한 구글 트래픽을 숨기고 내가 원하는 주소만 집중해서 보는 방법입니다.

### 방법 A: 필터 탭 활용 (추천)
- 우측 **[Filters]** 탭 선택 ➡️**`Use Filters`** 체크
- **Hosts** 구역 첫 번째 드롭다운을 `Show only the following Hosts`로 변경
- 아래 텍스트 박스에 대상 도메인 입력 (예: `localhost; naver.com`)
- 우측 상단 **[Actions]** 버튼 클릭 ➡️**`Run Filterset Now`** 선택
### 방법 B: 마우스 우클릭으로 간편 설정
- 좌측 패킷 리스트에서 대상 요청 우클릭
- **[Filter Now]**➡️**`Show Only '도메인주소'`** 선택
## 3. 요청(Request) 가로채기 및 수정
브라우저에서 서버로 데이터를 보내기 전에 값을 조작하는 방법입니다.

1. 키보드 **`F11`** 클릭 (또는 왼쪽 아래 상태 표시줄 클릭하여 위쪽 화살표 **[T]** 활성화)
2. 크롬 브라우저에서 요청 발생시키기
3. 피들러 좌측 리스트에 빨간색 아이콘(T)으로 멈춘 패킷 클릭
4. 우측 **[Inspectors]**➡️**[WebForms]** 또는 **[Raw]** 탭에서 데이터 수정
5. 우측 중간의 녹색 **`[Run to Completion]`** 버튼 클릭하여 서버로 전송
6. **종료 시:**`Shift + F11`을 눌러 가로채기 모드 해제 (하단 아이콘 빈칸 확인)
## 4. 응답(Response) 가로채기 및 수정
서버가 준 데이터를 브라우저가 받기 전에 값을 조작하는 방법입니다.

### 🛠️ 방법 A: 수동 수정 (일회성 테스트)
1. 키보드 **`Alt + F11`** 클릭 (또는 왼쪽 아래 상태 표시줄 클릭하여 아래쪽 화살표 **[▼]** 활성화)
2. 크롬 브라우저에서 페이지 새로고침 또는 요청 발생
3. 피들러 좌측 리스트에 **노란색 아이콘** 으로 멈춘 패킷 클릭
4. 우측 아래 창의 **[Transformer]** 탭 이동 ➡️**`No Compression`** 체크 (압축 해제)
5. **[TextView]** 또는 **[JSON]** 탭에서 서버가 보낸 결과 데이터 수정
6. 우측 중간의 녹색 **`[Run to Completion]`** 버튼 클릭하여 브라우저로 전달
7. **종료 시:**`Shift + F11`을 눌러 가로채기 모드 해제
### 🤖 방법 B: 자동 바꿔치기 (반복 테스트)
1. 우측 상단 **[AutoResponder]** 탭 선택
2. **`Enable rules`** 및 **`Unmatched requests passthrough`** 둘 다 체크
3. **[Add Rule]** 클릭
4. **Match 칸 (위)**: 가로챌 주소 입력 (예: `EXACT:[https://example.com/api/user](https://example.com/api/user)`)
5. **Action 칸 (아래)**: 반환할 방식 지정
- **[Find a file...]**: 로컬에 저장해 둔 가짜 JSON 또는 HTML 파일 지정
- **HTTP 상태 코드**: `404_NOTFOUND` 또는 `502_BAD_GATEWAY` 등 지정
6. **[Save]** 클릭 후 테스트 진행
