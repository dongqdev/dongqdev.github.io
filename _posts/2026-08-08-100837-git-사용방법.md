## 1. GitHub CLI (`gh`)를 사용하는 방법 (레포지토리 사전 생성 없음)

```plain text
# 1. 현재 프로젝트 폴더로 이동
cd my-project-folder

# 2. 로컬 Git 저장소 초기화 및 파일 커밋
git init
git add .
git commit -m "Initial commit"

# 3. GitHub CLI를 이용해 원격 레포지토리 생성 및 푸시
# (이 명령어를 실행하면 폴더명으로 GitHub 레포지토리가 자동 생성되고 push까지 완료)
gh repo create --source=. --public --push
```

- **특징:** 이 방식을 사용하면 웹사이트에 갈 필요 없이 로컬에서 모든 것이 해결
## 2. 순수 Git 명령어만 사용하는 방법 (웹에서 레포지토리 생성 )

```plain text
# 1. 현재 프로젝트 폴더에서 Git 초기화
git init

# 2. 올릴 파일들을 스테이징 영역에 추가 후 커밋
git add .
git commit -m "Initial commit"

# 3. 메인 브랜치명을 지정을 권장 (기본 master를 main으로 변경)
git branch -M main

# 4. GitHub 웹사이트에서 생성한 빈 레포지토리 주소를 원격(remote)지로 등록
git remote add origin https://github.com/유저명/레포지토리명.git

# 5. GitHub로 업로드
git push -u origin main
```
