요약: SAP RAP 개발 환경에서 사용하는 주요 파일 확장자는 CDS 뷰, 데이터 모델링, 비즈니스 로직, 서비스 정의를 구분하며, 이클립스 ADT에서 각기 다른 역할을 수행합니다.
SAP RAP(RESTful Application Programming Model) 개발 시 사용하는 주요 파일 확장자 및 역할은 다음과 같습니다.
### RAP 관련 주요 확장자 정리

| **구분** | **확장자** | **설명** |
| --- | --- | --- |
| **Data Model<br>(Data Definition Language Source)** | `.ddls` | CDS View (Data Definition)를 정의하며, 데이터 구조와 모델을 생성합니다. |
| **Metadata<br>(Data Definition Language Metadata Extension)** | `.ddlx` | Metadata Extension 파일로, UI Annotation 등을 별도로 분리하여 관리합니다. |
| **Behavior Definition** | `.bdef` | Behavior Definition 파일로, CRUD 작업 및 상태 관리를 위한 비즈니스 로직을 정의합니다. |
| **Projection** | `.bdep` | Behavior Projection 파일로, BDEF의 기능을 외부 노출용으로 매핑하거나 조정합니다. |
| **Service** | `.srvd` | Service Definition 파일로, 노출할 엔티티 세트와 서비스 인터페이스를 정의합니다. |
| **Binding** | `.bndl` | Service Binding 파일로, OData 버전 및 프로토콜(UI/API)을 설정하여 엔드포인트를 생성합니다. |

### 개발 참고사항
- **BDEF 생성 필수 컬럼**: RAP 테이블(DDLS) 설계 시 객체 생성을 위해 다음 컬럼이 필수적으로 포함되어야 합니다.
- `created_by` (생성자)
- `created_at` (생성일시)
- `last_changed_by` (최종 수정자)
- `last_changed_at` (최종 수정일시)
- **Key 설정**: 모든 테이블의 상단 키는 기본적으로 `key client : abap.clnt not null;`로 설정하여 클라이언트 종속성을 확보해야 합니다.
- **이클립스 확인**: 이클립스 ADT(ABAP Development Tools)에서는 위 확장자들이 각각 다른 아이콘과 뷰어로 구분되어 표시됩니다. 만약 프로젝트 탐색기에서 파일이 보이지 않는다면, ABAP 패키지 내의 해당 객체 유형이 올바르게 생성되었는지, 혹은 필터 설정이 되어 있지 않은지 확인해야 합니다.
