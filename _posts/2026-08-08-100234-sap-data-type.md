## 2. 영역별 특징
>  1. CBO 물리 테이블 (`define table`) 구역

- **특징:** HANA DB 등 실제 데이터베이스 스토리지에 물리적인 카탈로그 스키마를 생성하는 레이어입니다.
- **암기 팁:** 무조건 **대문자** 표준 형식을 사용하며, 온점(`.`)이 절대 들어가지 않습니다. `QUAN`, `CURR` 같은 수량/금액 타입은 반드시 상단에 `@Semantics` 어노테이션이나 우측에 `with referenced type`으로 단위 컬럼(`UNIT`, `CUKY`)을 링크해 줘야 빌드가 통과됩니다.
> 2. CDS 뷰 / 인터페이스 (`define view`) 구역

- **특징:** DB 테이블 위에 가상 뷰나 OData API 게이트웨이 파라미터(Abstract Entity 모달 팝업 등) 프로토콜 규격을 선언하는 레이어입니다.
- **암기 팁:** 반드시 앞에 `abap.` 이라는 접두사(소문자 온점)가 붙는 추상화 내장 타입을 사용해야 파서가 인식합니다. (단, `timestampl` 같은 일부 최신 데이터 원시 객체는 접두사 없이 통으로 소문자로 쓰기도 함)
> 3. ABAP 클래스 로컬 변수 (`DATA: TYPE ...`) 구역

- **특징:** Java의 Service 클래스 구현체 본문처럼 메서드 내부(`METHOD ~ ENDMETHOD`)에서 비즈니스 알고리즘, 사칙연산, 루프문을 돌릴 때 메모리에 임시 변수를 선언하는 원시 언어 레이어입니다.
- **암기 팁:** 고정 길이를 가진 문자나 숫자를 선언할 때는 전통적인 ABAP 문법 서식인 **`TYPE 데이터유형 LENGTH 길이`** 포맷을 준수해야 합니다. (수량/금액 계산용 Packed 타입의 경우 소수점 자릿수 지정을 위해 뒤에 `DECIMALS 자릿수` 구문이 필수로 붙습니다.
