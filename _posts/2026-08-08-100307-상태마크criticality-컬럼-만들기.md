## 1. Root View 에 코드 추가
```abap
...
define root view entity ZR_TWBS_TASK2 as select from ztwbs_task2
{

  // 기존 여부 필드 (Y / N 데이터 유지)
  coalesce(complete_yn, 'N') as CompleteYn,
  
  //UI5 엔진이 읽어갈 숫자 시그널 필드를 새로 팝니다.
  case coalesce(complete_yn, 'N')
    when 'Y' then 3  -- Y일 때는 초록색 체크 시그널(3) 전달
    when 'N' then 1  -- N일 때는 빨간색 엑스 시그널(1) 전달
    else 0
  end as CompleteCriticality,
```
## 2. Projection View 에 코드 추가
```abap
define root view entity ZC_TWBS_TASK2
  provider contract transactional_query
  as projection on ZR_TWBS_TASK2
  ...
  {
  ...
		CompleteCriticality,
	...
```
## 3. MetaData Extention 랜더링
```abap
@UI.lineItem: [ { position: 100, label: '완료 여부',criticality: 'CompleteCriticality' },
CompleteYn;
```
